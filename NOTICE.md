# Source and license notices

AngryMiao Battery Tray is a Windows port derived from LukePeltier/miaobat's protocol and battery-monitoring behavior. Original project: https://github.com/LukePeltier/miaobat. Distributed under GPL-3.0; see LICENSE.

Windows report interpretation also consulted HeyOkay/HaloBattery (MIT) and Aiacos/ajazz-control-center (GPL). Their license texts are retained in LICENSES; exact audited revisions and evidence are in docs/PORTING_ANALYSIS.md. No binary dependency on these projects is used.

Corresponding source is in AngryMiaoBattery-source.zip alongside the portable binary directory. Build the native executable using Visual Studio 2022 C++ Build Tools, Windows SDK and scripts/build.ps1. Preserve these notices and distribute source as required by the GPL when sharing binaries.
